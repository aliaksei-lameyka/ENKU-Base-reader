## Executed computational methods

Native KiCad10.0.7 all-severity ERC/DRC, every track error, schematic parity and refilled zones. Project minima and outline were preserved. R144 repairs an unsupported EPD-rule operator and adds a narrow0.15mm U11 internal pad-pair OEM exception; execution is tested with a sentinel. Historical ignored checks remain disclosed in native reports and are covered where applicable by independent source/land/manufacturer audits.

Current board:141 references /473 native pads /120 fitted top parts /19 bare PCB entries /R67 and R99 DNP /384 vias.93 reference fields and134 value fields are hidden;16 enabled layers are named uniquely. No unassigned tracks/vias/copper fills, copper graphics without net semantics or disabled documentation objects. Four copper layers exactly; the original rear Tag-Connect rule area is distinct from the antenna exclusion.

Independent methods use actual exported data, not regenerated old goldens:

- NumPy nodal analysis of feedback and TS; adversarial tolerance/temperature/current corners;50,000 seeded Monte Carlo scenarios; analytic slow-ramp RC models.18 deliberately wrong pin/value cases must be rejected. These are not SPICE or manufacturer macromodels.
- Pin-by-pin source/PCB/primary-land comparisons;finite R143-to-R144 changed source/net/component/copper delta, retained R143 J3 hold-down OEM correction; USB UUID/name/physical geometry equality. Numeric KiCad net-code indices are permitted to reindex when adding new nets.
- Gerbonara1.6.3 parsing and full-polarity rendering of all four copper images. Added/missing copper outside0.0052mm curve budget must be below1e-6mm2; discrete Hausdorff below0.0052mm.
- Complete11-layer Gerber metadata/units/revision, PTH/NPTH drill and four USB slot axes,456 emitted pad records plus384 via IPC356 records, whole-board mask/paste/silkscreen, native BOM/CPL, R67/R99 no-paste and six exact fill/cap requests.
- Independent Gerber conductor-island graph joined only by plated barrels, with actual pad labels independently IPC356 checked. No named-net opens/shorts accepted. In-memory copper bridge on U11 GND/RESET and copper cut on U11 supply must cause rejection. Original fabrication files are never mutated by these tests.
- Actual-layer centerline graphs and noded paths; three fixtures distinguish same-coordinate different layers, a real through-via and a same-layer crossing.30 explicit paths,14 fast-net reference metrics, via return distances and detours. No unresolved path accepted. Total-tree resistance, flight-time and capacitor-only droop scenarios are bounded models, not measured SI/PI.

The R144 workflow runs the same source-bound checks remotely. Its actual run result is recorded separately in GITHUB_R144.json after completion. No older run is labelled as current proof.
