# ENKU Base mainboard

Editable **Base R0.1** schematic, PCB and local KiCad libraries are stored in [`kicad/`](kicad/).

This is an **engineering first-spin**, not a fabrication-ready or production release. Before any manufacturing order, complete the [fabrication release checklist](../../docs/validation.md), including native KiCad ERC/DRC, connector orientation, component selections, display FPC fit and manufacturing-output review.

The Base does **not** include frontlight or wireless-charging circuitry. Those are outside this board's scope.
