# ENKU Base — остаток после R126

R126 закрепила 61 точный MPN и исправила физические площадки/локальную трассировку. **0 обрывов, ERC 0, parity 0; DRC 65 (45 library mismatch + 20 hole clearance).** [Изменения](COMPONENT_PASS_R126.md), [фактическое серверное доказательство](GITHUB_NATIVE_R126.md). Правила, исключения и электрические net nodes не менялись.

## Следующий инженерный проход

1. Закрепить оставшиеся 15 конденсаторов: C14/C15/C16/C17/C18/C19/C21/C22/C23/C27/C28/C29/C30/C38/C39. Проверить номинальные напряжения по фактическим цепям, C0G для C39 и геометрию. Для всех силовых/EPD MLCC посчитать худшую эффективную ёмкость с DC bias, tolerance, temperature и ageing; сопоставить с требованиями точных IC/панели. Сохранить проверенные MPN R126 до конкретного обоснования замены.
2. Выбрать точные R70 (26.7k, 0.1%, 25ppm), R71 (10k, 0.1%, 25ppm), R37 (2.2Ω, 1%, 0805); проверить мощность/импульсное ограничение R37 и точность/утечки высокоомных цепей. Их значения сейчас сохранены.
3. U1: согласовать сплошной EP 3.9², 12 thermal holes Ø0.3 с land Ø0.6, девять окон пасты 0.9² и минимум 0.1 mm nominal paste-to-hole. Чертёж производителя с девятью copper islands не воспроизведён; нужны реальные решения по via mask/wicking/stencil и монтажу. Это единственное оставшееся library pad/drill отличие.
