# ENKU Base R129 — IC, паста и сборочные данные

Исправлены реальные ошибки:

- У TPS63802 pad8 имел полный слой F.Paste поверх двух нарисованных окон. Фактический R128 SVG подтверждает сплошное окно1.3×0.25mm. Теперь pad8 только Cu/Mask, паста — две отдельные0.55×0.25mm площадки с R0.05mm и зазором0.20mm по TI4223750/D. Native SVG даёт83.17% геометрического покрытия; дробное отличие от идеальных83.29% вызвано аппроксимацией дуг SVG.
- BQ25185: EP0.9×1.5mm теперь с R0.05mm, паста0.85×1.38mm/R0.05mm по TI4226298/A. Старое окно0.84×1.41mm имело чрезмерный R0.21mm. Проверено реальное Cu/Mask/Paste, а не только текст библиотеки. Геометрическое покрытие native SVG86.87%; это не измеренный объём припоя. TI приводит разные примеры толщины трафарета:0.125mm для BQ и0.10mm для TPS. Общий процесс платы ещё требуется принять.
- Метка pin1 J7 была со стороны фактического pin2. Две линии перенесены к pin1: контакт33.73/86.365mm; угол метки33.095/85.73mm. Шесть контактов теперь типа connect, без пасты. Нумерация, сети, Cu/Mask, три NPTH и keepout сохранены.
- Десять устанавливаемых деталей имели unspecified mount type и выпадали из настоящего SMD-only CPL: U1,Q1,J2,U3,U4,U5,J3,J5,L1,L2. Теперь все97 устанавливаемых деталей присутствуют. В R128 их было87. R12/R67 DNP исключены;18 bare-PCB объектов (13TP,4H,J7) исключены из BOM/CPL.
- У TP подписи перенесены из пользовательской графики в видимое поле Probe Label с сохранением текста, координат, размера, стороны и зеркальности. Новые локальные определения TP/H/J5/J7 отражают намеренные свойства проекта; они не подтверждают монтажный fit или3D.
