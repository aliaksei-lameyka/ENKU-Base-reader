# ENKU Base — остаток после R123

R123 закрывает проверку локальной библиотеки microSD, исправление номинальной геометрии четырёх боковых кнопок, их символов и затронутых трасс. Локально: 0 разрывов, ERC 0, parity 0. Это ещё не готовая плата для заказа: 130 замечаний DRC остаются активны. Актуальный селектор доказательств — `hardware/mainboard/kicad/checks/current_checkpoint.json`.

## До выпуска файлов для заказа

Первыми идут геометрия отверстий кнопок и точный SW1. Это конкретные блокеры производства; дополнительные косметические проходы не заменяют их закрытие. Подготовленные вопросы поставщикам приведены в [SUPPLIER_QUESTIONS_R123.md](SUPPLIER_QUESTIONS_R123.md); сообщений в этом проходе не отправляли.

## После получения прототипов

Проверить питание и OFF/backfeed, заряд/нагрев, VBUS/hotplug/suspend, USB и EPD на реальном экземпляре. Поднять microSD, кнопки и дисплей. Реализовать и проверить USB MSC: компьютер получает эксклюзивное владение SD, reader возвращает filesystem после безопасного отключения. Для Base USB работает при включённом reader. Эти пункты относятся к bring-up прототипа и готовности изделия, а не заменяют проверку производственных файлов.

`fabrication_ready = false`. Исторический процент готовности не пересчитан: текущие решения опираются на перечисленные критерии.
