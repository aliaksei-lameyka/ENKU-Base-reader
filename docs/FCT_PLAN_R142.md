# R142 qualification procedures

**Status of every physical test: NOT RUN.** This is an acceptance procedure, not a record of a working prototype. Record board serial, source hash, BOM lot, panel/battery revision, firmware hash, fixture/instrument IDs, temperature, waveforms, limits and disposition for each test. A failed or missing prerequisite must remain visible. Stop at a limit violation; diagnose before repeating.

## Before fabrication or assembly

1. Resolve exact panel pin5 VDHR/VSH2 in writing against current GDEY0397T81P revision. Overlay actual24-pin FPC pin1/contact side/stiffener/insertion/fold with J3 and case. Verify the GDEM/GDEY CAD-name mismatch and obtain actual bend limits.
2. Review narrow joint3V3/reset/panel static margins and define measured PFM/startup/load limits; no dynamic voltage guarantee is inferred. Review resistor initial/TCR versus solder/lifetime drift separately. Select any required architecture change before releasing board artwork.
3. Approve actual stackup and90-ohm+-10% USB, copper/barrel thickness,84 nominal0.20mm bores on1.6mm PCB, hole/thickness/registration tolerances, four USB slots/stakes, six resin-fill/copper-cap sites and stencil/reflow/finish/flatness/void limits. Obtain supplier import preview for native absolute origin, top-side angles and exact fitted BOM.
4. Qualify finished thin protected2000-2500mAh pack: measured dimensions, polarity, PH2 mating/cable strain, PCM overcharge/overdischarge/overcurrent/short response, discharge pulse budget and charger compatibility. NTC is separately bonded to cell. No mainboard PCM exists.
5. Verify every physical component land/body/pin1, real procurement suffix, supplier substitute policy and package height in complete case CAD. There is no authorization to increase case thickness or add dock/frontlight/Hall/Qi.

## Firmware / functional tests

- UART J7 is3.3V logic only. Pin1 is VREF measurement, not power input. Wire adapter TX to board UART_RX, RX to UART_TX, common GND; use SW2 or J7 BOOT low while resetting through J7 EN. Verify ROM recovery through both UART and USB where supported. Never burn security/eFuse settings merely to exercise recovery.
- Build reviewed firmware with exact N16R8 settings; verify16MiB flash identity/address range and8MiB octal PSRAM with address/data patterns and stress, respecting settings/errata. Retain reproducible firmware hashes and logs. No released production binary currently accompanies this package.
- SPI SD: initialize at safe low clock, test several actual card sizes/vendors/lots, known-pattern read/write/hash after power cycles, insertion/removal during idle and access, filesystem recovery and current pulses. Check CS/MOSI/MISO/SCLK edge levels and ringing. Pullups include unused DAT1/2. GPIO39 detection is active-low after input/pulldown configuration and debounce.
- EPD: verify current panel revision/OTP/init/LUT behavior, BUSY active-high and timeouts, full/fast/partial/4-gray capability, portrait orientation, deep-sleep/wake and repeated refreshes at approved temperatures. Capture VGH/VGL/VSH/VCOM, boost switch/VGS, L2 peak/RMS current, diode inverse voltage and capacitor **differential** voltage including overshoot. Compare exact component limits and effective capacitance. Qualify R37 repetitive pulse/film temperature, not only average power.
- Shared bus: SD and EPD must never assert CS simultaneously unless explicitly supported. USB-MSC and local filesystem must have exclusive ownership of the same card; flush/unmount, transfer ownership, reconnect/removal/reset and corrupted-media recovery tests. Check data hashes before/after every ownership transition.
- BMI270: identify chip/address0x68, load correct Bosch config blob, verify INTERNAL_STATUS, self-test, axis signs, interrupt routing/latency and wake behavior. Bring up I2C100kHz; measure30-70% rise and bus capacitance. Use400kHz only with <=300ns rise and timing margins.
- ADC: wait at least500ms after switched rail is valid in the documented RC scenario. Compare battery voltage against calibrated meter across the operating range and temperature, ADC attenuation/sampling/loading/leakage. Voltage-to-SOC mapping requires battery-specific calibration; there is no fuel gauge.
- Charge: test USB100/USB500/ILIM/suspend transition order and authorization. Default USB100 limit includes system load. Verify CE toggling/status semantics,4.2V regulation/4.24V maximum under specified conditions, timer, charge termination/restart and battery supplement. Measure actual input current during enumeration, suspend, cable dropout and OFF. PGOOD or CC presence alone does not authorize500mA.
- NTC: controlled sensor/cell temperature at0/25/45C and wider permitted bounds; open/short sensor and R80/R81/R82/R89 fault insertion with current-limited safe fixture; leakage/thermal lag/detached sensor. Verify charge stops when required and log known non-fail-safe faults. A resistor network cannot detect every detached hot-cell sensor scenario.

## SI / PI / thermal / consumer qualification

1. Measure USB differential impedance/TDR on approved stack and USB functional/compliance behavior with representative cables/hosts/orientations. Correlate rise/eye/return-via results with geometry. Use IBIS/field solver only with actual stack, model and edge rates; none was available in this review.
2. Combined Wi-Fi TX, SD sustained write and EPD refresh, battery near cutoff, cold/hot product conditions; scope droop/overshoot and converter loop response, capture current and thermography with emissivity correction. Do not use capacitor-only droop or total-tree resistance as a converter simulation.
3. Check near-field emissions and immunity around boost/regulator switch nodes and SPI/USB/IMU. ESD contact/air tests at actual accessible surfaces using a defined approved plan and qualified setup. Verify ferrite/filter need from measured behavior.
4. Test RF throughput/range with actual case, protected pack, panel/FPC and user grip. Maintain designed antenna clearance and review all nearby metal; copper-free PCB is not final-product RF qualification.
5. Case, plug insertion/retention, SD insertion/eject travel, FPC bend/stiffener, switch/button/pusher engagement, battery replacement/strain, drops and connector cycles under defined consumer requirements. No complete current case fit has been closed.
6. Extended combined-load soak and repeated power/refresh/storage cycles, fault recovery and data integrity logging. Define duration/cycle count from product requirement;100-cycle bring-up checks are not a lifetime/reliability certification.

Close each item only against recorded evidence and agreed limits. Prototype manufacture may require a separate explicitly approved EVT risk disposition; production release requires completed qualification and manufacturer process acceptance. This document authorizes neither an order nor tests with an unqualified battery.
