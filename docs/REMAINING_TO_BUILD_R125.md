# ENKU Base — остаток после R125

R124 внедряет ранее утверждённый **G-Switch MK-12C03-G015**, исправляет общий контакт на вывод 2 и переносит выключатель к верхнему торцу. Выбирать SW1 заново не требуется. Чертежи его разных ревизий ещё нужно согласовать; [разбор](SW1_DRAWING_REVIEW_R124.md). R125 исправляет 11 площадок Q1/Q2/U9 по первичным чертежам; [разбор](COMPONENT_LANDS_R125.md). Локально и на фактическом серверном KiCad **0 обрывов, ERC 0, parity 0; 126 активных замечаний DRC**. [Серверное доказательство R125](GITHUB_NATIVE_R125.md) подтверждает именно исходный commit 83a16b2e627009d9d1e6e2516fb939ac64e05a27.

## После изготовления прототипа

Проверить OFF/backfeed, заряд и нагрев, VBUS/hotplug/suspend, display power, кнопки и SD на реальной плате. Поднять EPD и USB MSC с эксклюзивным владением SD со стороны компьютера и безопасным возвратом reader filesystem после отключения. Base USB работает при включённом reader. Эти задачи относятся к bring-up и изделию; они не заменяют проверки производственных исходников.

**`fabrication_ready = false`**. Старые проценты готовности не переносятся на R124. Учёт подтверждённых интервалов разработки ведётся в `DEVELOPMENT_HOURS_READER.json`; историческая сумма неизвестна.
